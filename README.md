# 🍌 국민 컴퓨터용 스피커 5종 비교 대시보드

빙그레 바나나맛 우유 헤리티지 테마로 제작된 **컴퓨터용 스피커 추천 및 비교 웹 대시보드**입니다.  
사용자 환경에 맞춘 반응형 인터페이스(PC & 스마트폰)를 제공하며, A4 인쇄/PDF 저장 기능을 갖추고 있습니다.

---

## 📌 주요 특징
1. **바나나맛 우유 헤리티지 UI**: 친근하고 따뜻한 옐로우/그린 컬러와 둥근 단지 곡선 레이아웃.
2. **엄선된 5개 카테고리 스피커**:
   - `브리츠 BA-R9 SoundBar`: 1만원대 모니터 하단 거치 가성비 사운드바
   - `크리에이티브 PEBBLE V3`: C타입 단일 케이블 & 블루투스 5.0 데스크테리어 스피커
   - `에디파이어 MR4`: 42W RMS 고출력 4인치 우퍼 목재 하이파이 모니터링
   - `로지텍 Z150`: 독립 AC 어댑터 전원으로 노이즈 없는 인강/화상회의용 2.0
   - `크리에이티브 페블 프로`: 바닥면 RGB 무드 라이팅 & BassFlex 저음 강화 모델
3. **단독 상품 페이지 직결**: 검색 결과 목록이 아닌, 쿠팡 1개 단독 상품 상세 페이지(`vp/products/...`)로 1:1 연결.
4. **인쇄 및 PDF 다운로드 지원**: `🖨️ 인쇄 / PDF 저장` 버튼을 통해 견적서/비교표 형식으로 깔끔하게 출력 가능.
5. **독립 실행 지원**: `shopping-compare.html` 단독 파일로 서버 없이 더블 클릭만으로 오프라인/로컬 브라우저에서 실행.

---
